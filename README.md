# Le Parc à Huîtres · Hendaye

Site vitrine du Parc à Huîtres (Perle d'Hendaye), 5 rue des Orangers, 64700 Hendaye.

Une page statique (`index.html`), publiée avec GitHub Pages. Le contenu (carte, huîtres, à emporter, horaires,
coordonnées, textes) est dans `content/*.json` et se modifie depuis l'espace admin :
https://u8tscared.github.io/parc-huitres/admin/ (mode d'emploi : [ADMIN.md](ADMIN.md)).

Réservation et vente à emporter en démo, à connecter à Growth Gusto.
